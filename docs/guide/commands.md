# 常用命令

只列玩家真正用得上的命令。输入时按 **Tab** 可以自动补全，
打错了多半是权限或版本问题，看屏幕红字提示。

::: tip 记不住？
游戏里输入 `/` 后按 Tab 翻一遍最直接。
整合包原版功能的完整命令表见
[官方命令文档](https://doc.ideafox.top/docs/Midnight/zeronight/zeronight-commands)。

## 菜单（最省事的入口）

一个菜单点到底，三种打开方式任选：

| 方式 | 操作 |
| --- | --- |
| 手持「菜单」钟 | 直接**右键**（进服会自动发一个，物品名写着「菜单」） |
| 快捷键 | **潜行 + F**（切换副手键，必须潜行） |
| 命令 | `/menu` |

菜单里的入口：传送系统、功能菜单、个人菜单、签到、世界市场、战令、
任务、红包、领地、公会、投票踢出。基岩版玩家会多一个「基岩版个人菜单」；
管理员才会看到「管理员面板」。

- **传送系统**：主世界 / 地狱 / 末地、主城、随机传送、返回上一个位置
- **功能菜单**：铁砧、工作台、砂轮、锻造台、公共垃圾桶、戴帽子、坐下、躺下
- **个人菜单**：设置家、家列表、末影箱、刷新皮肤、称号仓库、个人信息

## 账号（进服第一件事）

| 命令 | 作用 |
| --- | --- |
| `/register <密码> <确认密码>` | 注册账号（首次进服必做，**同一 IP 最多注册 2 个**） |
| `/login <密码>` | 登录（每次进服都要，**90 秒内**没登录会被踢出） |
| `/changepassword <旧密码> <新密码>` | 修改密码 |
| `/logout` | 注销当前登录状态 |

## 家与传送

| 命令 | 作用 |
| --- | --- |
| `/sethome` | 把脚下设为家 |
| `/home` | 回家（默认家） |
| `/home <家名>` | 回指定的家，例如 `/home shop` |
| `/delhome` | 删除当前所在的家 |
| `/homelist` | 查看自己的家（图形界面） |
| `/spawn` | 回出生点 |
| `/back`（`/dback`） | 回到上一个位置（死亡后可回尸体处） |
| `/rtp` | 随机传送到野外，找地方安家用（**冷却 30 秒**） |
| `/tpa <玩家>` | 请求传送到对方那里，等对方同意（等价于 `/ptp request`） |
| `/tpahere` | 让对方传送到你这里（等价于 `/ptp invite`） |
| `/tpyes <玩家>` | 同意对方的传送请求 |
| `/tpno <玩家>` | 拒绝对方的传送请求 |
| `/tptoggle` | 开关自己是否接收传送请求 |
| `/afk` | 挂机标记，避免被判定为离开 |

::: warning 随机传送的范围
`/rtp` 在主世界传送到原点 ±15000 方块内，下界 ±5000，
**末地不能用**。传送时会短暂失明并带传送门粒子，属正常表现。
:::

## 红包（聊天栏互动）

| --- | --- |
| `/fhb money <金额> <个数> [口令] [指定玩家]` | 发金币红包，加 `luckyavg` 为拼手气 |

## 领地（Dominion）

| 命令 | 作用 |
| --- | --- |
| `/dom menu` | 领地主菜单（推荐从这里点） |
| `/dom create <名称>` | 用选定点创建领地 |
| `/dom auto_create <名称>` | 在脚下快速圈一块领地（半径 10） |
| `/dom list` | 查看自己的领地 |
| `/dom tp <领地名称>` | 传送到自己的领地 |
| `/dom expand <格数> <方向>` | 扩大领地（方向如 north/east/south/west/up/down） |
| `/dom resize <扩展\|收缩> <格数> <方向>` | 精确调整领地大小 |
| `/dom member_add <领地名称> <玩家>` | 把朋友加进领地一起建造 |
| `/dom set_tp <领地名称>` | 设置领地传送点 |
| `/dom help` | 领地命令帮助 |

`/dom` 就是 `/dominion` 的别名。出生点半径 10 内禁止圈地，
**180 天不上线，领地会被自动清除**。

领地玩法细节（选点、权限标志、群组）看
[领地插件教程](https://doc.ideafox.top/docs/Midnight/midori-dream/dom-help) 与
[命令速查](https://doc.ideafox.top/docs/Midnight/Other-Docs/dominion-help)。

## 基岩版专属菜单（Geyser）

这些菜单主要给基岩版玩家，Java 玩家用不到：

| 命令 | 作用 |
| --- | --- |
| `/geyser advancements` | 查看 Java 版进度 |
| `/geyser statistics` | 查看统计信息 |
| `/geyser settings` | 设置菜单 |
| `/geyser offhand` | 把手上物品放到副手 |

::: warning 别乱用管理命令
WorldEdit（`//` 开头）、封禁类命令都是给管理员的，
普通玩家输入只会收到「没有权限」。
:::

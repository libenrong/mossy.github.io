# 常用命令

本页列出 MossyMC 的常用命令。

::: warning 注意
以下为 Minecraft 服务器通用命令参考，具体可用命令与权限以服务器内实际配置为准。可在游戏内输入 `/help` 查看完整命令列表。
:::

## 基础命令

| 命令 | 说明 |
| --- | --- |
| `/spawn` | 返回出生点 |
| `/home <名称>` | 传送至指定家 |
| `/sethome <名称>` | 设置一个家 |
| `/delhome <名称>` | 删除指定家 |
| `/bed` | 传送到床的位置（已设置重生点时） |

## 传送命令

| 命令 | 说明 |
| --- | --- |
| `/tpa <玩家>` | 请求传送到指定玩家 |
| `/tpahere <玩家>` | 请求指定玩家传送到你身边 |
| `/tpaccept` | 接受传送请求 |
| `/tpdeny` | 拒绝传送请求 |
| `/warp <名称>` | 传送到指定公共传送点 |
| `/back` | 返回上一个位置（如死亡地点） |

## 领地命令

| 命令 | 说明 |
| --- | --- |
| `/claim` | 使用金锭圈选并认领领地 |
| `/trust <玩家>` | 授予玩家在领地内的权限 |
| `/untrust <玩家>` | 移除玩家领地权限 |
| `/claimlist` | 查看你拥有的所有领地 |
| `/abandonclaim` | 放弃当前所在的领地 |

## 经济命令

| 命令 | 说明 |
| --- | --- |
| `/balance` | 查看你的余额 |
| `/pay <玩家> <金额>` | 向指定玩家转账 |
| `/baltop` | 查看财富排行榜 |

## 信息命令

| 命令 | 说明 |
| --- | --- |
| `/help` | 查看可用命令列表 |
| `/list` | 查看在线玩家 |
| `/rules` | 查看服务器规则 |
| `/motd` | 查看服务器每日公告 |
| `/msg <玩家> <内容>` | 私聊指定玩家 |

::: tip 小技巧
输入命令时按 `Tab` 键可自动补全玩家名称或命令参数。
:::

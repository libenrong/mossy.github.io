# 新手入门

欢迎来到 MossyMC！本页将引导你完成首次加入服务器的全部步骤。

## 加入服务器

### 服务器地址

```
mossymc.top
```

### 客户端要求

- **Java 版 Minecraft**（具体版本以服务器内公告为准）
- 基岩版同步开放，可在基岩版多人游戏中直接添加服务器

### 加入步骤

1. 启动 Minecraft Java 版
2. 点击 **多人游戏** → **添加服务器**
3. 服务器地址填入 `mossymc.top`
4. 点击 **完成**，双击服务器进入

::: tip 提示
如果显示「无法连接至服务器」，请检查网络连接，或确认客户端版本是否与服务器匹配。
:::

## 首次进入

### 出生点

首次进入服务器后，你将出现在出生点区域。出生点通常设有：

- **新手指引牌** — 阅读规则与基础信息
- **传送面板** — 前往各个世界或区域
- **商店区** — 购买起步物资

### 第一步建议

1. **阅读规则** — 在开始游戏前，请先阅读 [服务器规则](/rules)
2. **认领领地** — 使用领地插件保护你的建筑（参见 [常用命令](/guide/commands)）
3. **采集资源** — 前往资源世界采集木材、矿石等基础物资
4. **安家落户** — 选择合适的位置建造你的第一个基地

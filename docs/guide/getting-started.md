# 新手入门

欢迎来到苔石Server！这一页带你从零进服，全程只讲你用得上的事。

## 一、进服信息

| 项目 | 内容 |
| --- | --- |
| Java 版地址 | `mossymc.top`（填这个就行，不用带端口） |
| 基岩版地址 | 同样填 `mossymc.top`；填不上就用 `play.simpfun.cn:30843` |
| 推荐 Java 版本 | **1.21.7 — 26.3**（界面功能最完整） |
| 也能进的版本 | 1.20 — 1.21.6 照样能进，只是部分新界面不显示 |
| 基岩版本 | 26.30 — 26.5x |
| 收费 | 免费，基岩版也不需要正版账号 |

::: tip 关于版本
推荐 1.21.7 起是因为部分 Dialog 界面需要新客户端；旧版本能进服、能玩，
只是个别界面会缺。用什么版本进服，以你自己顺手为准。
:::

## 二、三步进服（Java 版）

1. 打开 **多人游戏** → **添加服务器**
2. 地址填 `mossymc.top`，完成
3. 双击进服，然后**注册账号**（见下节）

基岩版玩家：**服务器 → 添加服务器**，地址一样；手机、主机、Win10 都可以，
进服后和 Java 玩家在同一个世界。

## 三、第一次进服必须做：注册

服务器是注册制，**不注册什么都干不了**：

```
/register 你的密码 你的密码
```

之后每次进服：

```
/login 你的密码
```

要改密码用：

```
/changepassword 旧密码 新密码
```

::: warning 密码就是你的账号
服务器通过密码认人，**密码丢了物品建筑很难找回**。
选个记得住但别人猜不到的，不要和别人共用。
:::

::: tip 基岩版玩家
基岩版玩家 ID 会自动带上 `-` 前缀（例如 `-Steve`），一般会提示你直接注册，
按提示设置密码即可。
:::

## 四、进服后先干这几件事

1. **读规则** — 看一眼 [服务器规则](/rules)，少踩坑
2. **开荒传送** — `/rtp` 随机传送到野外找地方安家
3. **设家** — 到了合适的位置 `/sethome`，下次 `/home` 直接回来
4. **圈领地** — `/dom` 创建领地，别人就动不了你的方块，
   详见 [常用命令](/guide/commands#领地dominion)
5. **摸清玩法** — `/sf` 打开科技魔法指南，`/bp` 看战令，`/signin` 签到

## 五、进不去 / 连不上怎么办

按顺序排查：

1. **版本对不对** — 推荐 1.21.7+，太旧的版本会被挡（[常见问题](/faq) 有说明）
2. **地址填没填对** — 只填 `mossymc.top`，别带 `http://`，也别随便加端口
3. **还连不上** — 换直连地址 `play.simpfun.cn:30843` 试试
4. **卡在登录** — 看屏幕提示，超时了就重新进再 `/login`
5. **还是不行** — 加 QQ 群 **391425109**（游戏内公告栏也有），把报错截图发出来问

# 世界生成类数据包：跑图能遇到什么

这一页写给**完全没碰过这些扩展包**的人。你可能听说过「数据包」三个字就头大，
其实说白了：它就是服务器自己装的一堆内容，**你什么都不用装**。

数据包是跑在服务端上的，玩家进服就自动吃到——Java 版、基岩版都一样能见到新地形、新建筑，
不用去下载 Forge、Fabric，也不用换客户端，什么都不用动。

这类包里有一批是专门管**世界生成**的：它们只在你**探索新地方的时候**起作用。
已经跑过的区块是「定稿」的，不会凭空变形、不会把你家地基掀了，所以放心跑图。

想看新东西只有一个办法：**去没去过的地方**。手上有 `/rtp`（随机传送，30 秒冷却），
一下就把你扔到野外；想精准点，主菜单 →「传送系统」可以直接去主世界 / 地狱 / 末地。
（`/rtp` 在末地用不了，末地只能走传送门或者菜单传送。）

::: tip 想看全部 8 个数据包？
本页只讲**世界生成类**的 5 个。另外 3 个（深渊核心、废土纪元、战斗塔）是
**主动进入才能玩**的内容，总览和进入方式见
[数据包新内容](./datapacks)。
:::

::: tip 一句话记住
新内容 = 新区块。原地站着不动，等是等不来的。
:::

## Terralith：主世界地形与群系大修

**这包是干嘛的**：把主世界的地形和生物群系整个重做一遍，让你跑图的时候一直有新鲜感。

它是**纯世界生成**——没有任何每 tick 跑的游戏逻辑，就是决定「区块长什么样」。
只影响**新生成的区块**，你已经探索过的区域一点都不会变。

你会看到这些：

- **95 个新生物群系**，其中 **11 个是洞穴群系**，挖矿也一样有惊喜
- **28 种新结构**、**7 个结构集**（地下地牢、地下建筑、废墟、普通建筑、
  法师建筑、稀有地牢、稀有村庄）
- 地表群系举例（游戏内按中文名显示）：火山口、紫水晶峡谷、樱花谷、沙漠绿洲、
  天空群岛（春夏秋冬各一款）、台地、约塞米蒂悬崖、冰川裂谷、白色方山、
  繁花高原、薰衣草森林、黄石
- 洞穴群系举例：地热洞穴、地幔洞穴、真菌洞穴、蠹虫洞穴、霜火洞穴、花岗岩洞穴
- 结构举例：法师塔（四季各一款，外加法师建筑群）、要塞村庄、沙漠要塞村庄、
  沙漠前哨、矿井前哨、冰川小屋、冰屋、冰封地牢、山谷旅舍、地下小屋、
  女巫小屋、沉没高塔、旧炼油厂、巨型蜂巢，以及森林 / 丛林 / 沙漠 / 方山 /
  群山 / 针叶林六类废墟

**怎么去**：`/rtp` 随机传送到野外，往没走过的方向跑；或者主菜单 →「传送系统」换地方。

**给新手的建议**：

1. 出门先看 F3 群系名，看到没见过的名字就说明你已经跑进新内容了
2. 洞穴也别放过——11 个洞穴群系很多都在地下，正常挖矿就能撞上
3. 见到法师塔、要塞村庄这类大结构，先绕一圈摸清怪再进，别一头扎进去

## Structory：散落世界的遗迹

**这包是干嘛的**：在主世界各处随机丢小遗迹，让你跑图路上不至于一直看空地。

它**不加新群系、没有每 tick 逻辑、也没有任何自定义文案**，纯粹是往世界上摆建筑。
同样只影响新生成的区块。**15 类结构 + 5 个结构集，共 238 个结构模板**——
注意这里面大量是纯装饰件（桌椅、告示牌、篝火之类），所以「238」听着吓人，
实际是很多小零件拼出来的。

你会遇到这些结构：

| 类型 | 具体有哪些 |
| --- | --- |
| 营地与居所 | 废弃营地、旧庄园、沙漠流浪者、草原流浪者 |
| 宗教与丧葬 | 废弃礼拜堂、墓地 |
| 水域与沼泽 | 废弃木船、沼泽废墟 |
| 林地废墟 | 密林废墟、丛林废墟、草地废墟、北方废墟 |
| 针叶林遗迹 | 地表针叶林遗迹、地下针叶林遗迹 |
| 其他 | 瞭望火塔 |

（结构集共 5 个：废墟、中型稀有废墟、幽静废墟、旧庄园、流浪者。）


**怎么去**：`/rtp` 落地后正常走路就行，这类结构是散落分布的，不用刻意找。

**给新手的建议**：

1. 小屋、营地这类点看到就进去翻，是前期捡补给最省事的路子
2. 废弃木船、沼泽废墟在水边，沿着河和海岸跑图命中率更高
3. 遗迹是「路过顺手」的内容，别专门为它规划路线，跑图时自然会遇到

## Geophilic：给原版群系加细节

**这包是干嘛的**：不加新群系，而是把**原版自带的群系**装修得更细、更有生活感。

它覆盖 **29 个原版生物群系**，往里面塞：倒木、树桩、灌木丛、花丛、碎石堆、
地表矿脉、以及改造过的熔岩湖。**纯装饰**，没有每 tick 逻辑，不加怪也不加物品。

有两个容易搞错的点，先说清楚：

- 它改的是**原版群系**，不是新增群系——所以你在 F3 里看到的还是熟悉的名字
- 因为改的是原版群系，它**没有可汉化的自定义名称**（原版自带中文，直接就是中文）

**怎么去**：不用专门去。`/rtp` 落到任何原版群系里，都能看到它的效果；
注意它同样**只影响新生成的区块**。

**给新手的建议**：

1. 别指望靠群系名发现它——这包是靠「地面比以前丰富」体现的
2. 地表矿脉是顺手福利，跑图时看到裸露矿可以顺手挖
3. 熔岩湖被改造过，路过照常小心火，规则没变

## Nullscape：末地重做

**这包是干嘛的**：把末地的地形和浮岛分布整个重做，末地不再是打完龙就没得逛的地方。

它加了 **3 个新群系**：水晶峰、阴影荒原、虚空荒原；
**2 个新结构**：龙骨残骸、裂隙。

::: tip 末地的重点
只影响**新生成的末地区块**。你已经探过的末地主岛和末地城**不会被改写**，
要**往远走**才能见到新地形——打完龙别急着回家，绕着往外飞。
:::

它的启动提示（toast）和成就都**已汉化**，进末地时留意一下弹出来的提示。

**怎么去**：走主世界通往末地的传送门；或者主菜单 →「传送系统」直达末地。
（`/rtp` 在末地不能用。）

**给新手的建议**：

1. 主岛边缘之外才是新内容，从岛边出发一直往外飞
2. 末地城是否被改写以游戏内实际为准，探过的区域不会凭空变化
3. 新地形没探之前别乱跳，虚空摔落是不讲情面的

## Incendium：下界扩展（本服内容量最大的数据包）

**这包是干嘛的**：给下界塞进一整套新群系、新结构、Boss 和装备，
是本服**内容量最大**的世界生成类数据包。

**8 个新下界群系**：灰烬荒原、炼狱沙丘、倒置森林、石英平原、剧毒废料堆、
火山三角洲、哀泣山谷、凋灵森林。

**9 座新结构**：废弃高塔、禁忌城堡、炼狱祭坛、下界反应堆、猪灵村庄、管道、
石英厨房、破败实验室、圣所。

**Boss**：悬空狱火与增强版凋灵——下界比原版危险得多。

**约 30 件自定义武器 / 工具 / 盾牌 / 护甲**，例如：

炽焰短斧、寒彻之刃、火风暴、献祭巨剑、沉重铁镐、多重连射、死灵盾牌、棱光盾牌、
辐射盾牌、诸神黄昏、不安自然、绯红匕首、斥候战盔、哨兵之怒、开拓者、伏特三叉戟、
凋灵克星、扭曲凋灵之刃、破晓者、神圣愤怒、炼狱之翼、归还卷轴，以及防化四件套。

另有附魔「**毒性保护**」，以及一道**鞘翅升级配方**（用炼狱之羽升级鞘翅）。

**61 个成就**（成就面板里可见 40 个）——**已汉化**，
打开成就面板就能看到它的任务线，照着走基本就是这个包的攻略顺序。

::: warning 下界强度提醒
Incendium 是本服**唯一带常驻每 tick 逻辑**的世界生成类包，服务端已经针对它做过性能优化，
玩家不用管这些技术细节。你只需要记住一条：**下界内容强度高，别空手下界。**
穿好装备、带够食物和垫脚方块再进去。
:::

**怎么去**：主世界下界传送门，或者主菜单 →「传送系统」直达地狱。

**给新手的建议**：

1. 第一次去先打开成就面板，照着它的任务线走，别瞎逛送人头
2. 见到新结构先在外围看清守怪再动手，这包的结构不是白给的
3. 捡到自定义装备别随手卖掉，那是这个包的精华，具体属性以游戏内实际为准

## battle_towers：战斗塔

**这包是干嘛的**：在主世界和下界各丢一套**战斗塔**，给玩家一个稳定刷怪刷装备的地方。

- **主世界和下界各有一套结构集**，随机生成
- 每座塔分**三层**：塔基、楼层、塔顶
- **楼层**里有刷怪笼和战利品箱，**塔顶是奖励层**
- 已汉化（包描述与内部名称）

**怎么去**：`/rtp` 之后跑图留意高塔；下界那一套走传送门进去找。
具体生成位置随机，以游戏内实际为准。

**给新手的建议**：

1. 看到塔就上去清一层拿一层，别一口气冲顶，刷怪笼还在下面活着
2. 进塔前放一张床或者记住入口方向，死了好回来捡东西
3. 下界版的塔更凶，装备没成型之前先打主世界版练手

## 常见问题

::: warning 这几个问题问得最多
1. **为什么我看不到新地形？** —— 这类包**只在新生成的区块生效**，已探索区域不会变。
   `/rtp` 传送到远处，或者走远一点再看。
2. **要不要装模组 / 资源包？** —— 不用。全是服务端数据包，什么都不用装，
   Java 和基岩进服就自动生效。
3. **名字显示英文怎么办？** —— 本服这批包**已全部汉化**；
   Geophilic 改的是原版群系，原版本来就是中文，它自己没有自定义名称。
4. **会影响服务器流畅度吗？** —— 纯生成类的包只在生成区块时计算，平时不占性能。
   只有 Incendium 带常驻逻辑，服务端已做过优化，你正常玩感觉不到差别。
5. **下界有什么要注意的？** —— Incendium 内容强度高，**别空手下界**：
   穿好装备、带够补给，Boss 和新结构都比原版下界难对付。
:::

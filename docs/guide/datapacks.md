# 数据包新内容

本服装了 8 个数据包，加起来是**几百个新群系、上百座新结构、两套独立维度玩法**。
下面每一条都按服务器上数据包的实际文件核对过，不是网上抄的版本说明。

## 一、主世界：Terralith · Structory · Geophilic

这三个包都是**纯世界生成**，不加怪、不加物品，只是让跑图更有东西看。

### Terralith —— 地形与群系大修

- **122 个新生物群系**，例如：火山口、紫水晶峡谷、樱花谷、苍翠高原、沙漠绿洲、
  冰川裂谷、草原台地、白垩悬崖、高原针叶林、废弃荒漠……
- **21 种新结构**：法师塔（春夏秋冬四个版本）、要塞化村庄、沙漠前哨、冰川小屋、
  各类废墟（森林 / 丛林 / 荒漠 / 山地 / 针叶林 / 台地）、山谷旅舍、地下小屋、
  女巫小屋、地下遗迹
- 洞穴里也会生成新的**洞穴群系**，地下探险比原版丰富得多

### Structory —— 散落世界的遗迹

16 类结构，共 238 个结构模板（其中大量是纯装饰件，比如告示牌、桌椅、篝火堆）：

| 结构 | 说明 |
| --- | --- |
| 废弃营地 / 老宅 / 墓地 | 适合当出生点附近的第一处据点 |
| 废弃礼拜堂 / 密林废墟 | 主世界森林与丛林中 |
| 沉船、沼泽废墟、北方废墟 | 水域与针叶林地带 |
| 荒漠 / 草地流浪者小屋 | 有人住过的小屋，常有储物 |
| 针叶林废墟（地表 + 地下） | 同一结构分地上地下两种 |

### Geophilic —— 把原版地形做细

- 覆盖 **29 个原版生物群系**，往里面塞倒木、树桩、灌木丛、花丛、碎石堆、
  地表矿脉、改造过的熔岩湖
- **纯装饰**：不加结构、不加怪物，只让原版地形看起来更自然

## 四、独立维度：Deeper Dark「深渊核心」

> 全套内容已汉化，成就线、附魔、物品名都是中文。

### 怎么进去

::: tip 进入方式
1. 拿到**回响碎片**（主手拿着）
2. 走到**远古城市**的传送门框架，站上**强化深板岩**
3. 直接被传送进深渊核心——**不需要打火石**

进深渊核心时系统会给你一枚记录了入口坐标的**入口碎片**，想回来就拿着它原路返回。
:::

- 若你正在被**监守者**追杀（50 格内有监守者），出口会把你拦下——成就「被拒之门外」
- 传送有冷却，别指望连跳

### 7 个生物群系

| 群系 | 特点 |
| --- | --- |
| 深渊核心 | 维度基础群系 |
| 远古黑暗 | 幽匿的故乡，触碰幽匿会被它「记住」 |
| 深渊核心洞穴 | 主体洞穴层 |
| 火山洞窟 | 熔岩与火光 |
| 紫水晶矿坑 | 配套紫水晶矿井结构 |
| 深处绿洲 | 稀有水源绿洲 |
| 黑曜石屏障 | 地下边界层 |

### 5 类结构

紫水晶矿井、远古堡垒、远古村落、实验室、幽匿陷阱。
三种**定位罗盘**可以帮你找它们：紫水晶矿井定位罗盘、远古堡垒定位罗盘、实验室定位罗盘。

### 7 个附魔（附在不同部位）

| 附魔 | 部位 | 效果 |
| --- | --- | --- |
| 明目 | 头盔 | 清除失明 I，减轻黑暗影响 |
| 音波爆轰 | 胸甲 | 充能后发射音波攻击（可自定义伤害） |
| 安然落地 | 护腿 | 提高安全掉落高度 |
| 暗影疾行 | 靴子 | 完全黑暗中提升移速 |
| 共鸣 | 盾牌 | 攻击者发光，并能格挡音波攻击 |
| 尖啸感知 | 望远镜 | 隔墙标示你瞄准的尖啸体或监守者 |
| 深掘 | 工具 | Y=0 以下或在深渊核心中挖掘更快 |

### 核心机制

- **Boss「守卫者」**：带专属血条，击败后有独立成就
- **幽匿转化器**：把物品丢进转化器，用「附魔追加」为已附魔物品再随机加一条相容附魔
- **幽匿触手 / 之爪 / 虹吸器 / 反催化剂 / 音波冲击枪**：投掷放置的方块型道具
- **监守者追踪器**：手持会读出「远古黑暗注意到你了」的警告等级
- **冲击波**：会摧毁地形的音波攻击（可被游戏规则开关）

### 成就是它的任务线

按背包里的**成就页签**（或按 `L`）打开进度面板，从「宝藏与危险」一路做到
「当黑暗褪去之时……」，基本就是这个维度的完整流程攻略。

## 五、独立维度：Ruined「废土纪元」

> 全套内容已汉化。这是一个**放射性荒原玩法大修**，独立于原版生存之外的一整套系统。

### 怎么进去

::: tip 进入方式
主世界会**自然生成「入口废墟」结构**（不是能自己搭的门）。
走进去就会被自动传送进废土，出生点在高空（自带缓降与抗性，不会摔死）。
:::

- 入口约每 **36 格距**刷一处，跑图时留意地面上的废墟
- 从废土回来同样走入口结构

### 14 个生物群系

酸液沼泽、黑水泥沼、灰烬荒原、爆轰之地、枯骨旱地、死木林、玻璃旷野、
冲击高地、辐照废土、辐木林、锈蚀荒原、硫磺河、硫磺温泉、沉沦废土、
剧毒平原、真菌隔离区（部分为水系 / 河流群系）

### 盖革计数器

进入废土后，**动作栏会一直显示你当前所在的群系**，
以及辐射威胁等级：`盖革：较低` → `盖革：升高` → `盖革：危险`。

### 21 个附魔

余震、电弧连锁、破防矩阵、电容眩晕、腐蚀打击、流血、猎人标记、生命线、
变异克星、超频、相位打击、地震铲矩阵、反应堆涌动、反应堆护符、裂隙钻机矩阵、
打捞锯矩阵、拾荒者、电击箭、污泥爆裂、压制力场、废土之跃

### 4 套成品套装

| 套装 | 槽位 | 特点 |
| --- | --- | --- |
| 防化 Mk II | 4 件 | 部分危险防护，与防化装备搭配 |
| 变异甲壳 | 4 件 | 击杀变异体掉更多材料 |

另有坦克胸甲、废料盾、长手巨剑、地震铲、裂隙钻机、打捞锯等特化装备——
多数工具带**潜行敲击**的范围挖掘（3×3×3 空腔、5 格隧道等）。

### 药剂与负面状态

- 常用药剂：兴奋针、肾上腺注射剂、净化凝胶、Rad-X 注射器、专注药片、
  铁肤补剂、相位补剂、猎人针剂、背水一战针剂、密封医疗包、密封作战口粮
- 会中**辐射病、腐蚀、流血**等负面状态，**净化凝胶 / 除污喷雾**可以清掉
- 手持**盖革计数器**还能扫描附近的变异体密度

### 结构

入口废墟（传送点）、地表废墟、稀有补给点，以及两种地形：
**深缝**（deep fissure）与**伤痕峡谷**（scar canyon）。

## 六、战斗塔 battle_towers

- **主世界和下界各有一套**战斗塔，随世界随机生成
- 每座塔分三层：塔基 `start`、楼层 `floor`、塔顶 `top`
- 楼层刷怪笼 + 战利品箱，塔顶是奖励层

塔是前期练级和刷装备最稳定的地方，看到塔就上去清一层拿一层。

## 常见问题

::: warning 关于这几个包
1. **为什么我看不到新地形？** —— 只在新区块生效，`rtp` 去远处。
2. **要装模组或资源包吗？** —— 不用，全是服务端数据包，Java 和基岩都能体验到。
3. **为什么有些名字是英文？** —— 只汉化了深渊核心、废土纪元、战斗塔，
   Incendium / Terralith / Nullscape / Structory / Geophilic 仍是英文原名。
4. **这些内容会影响服务器流畅度吗？** —— 地形类的包只在生成区块时计算，
   平时不占性能；只有两个独立维度包有常驻逻辑，服务端已做过优化。
:::

## 一、主世界：Terralith · Structory · Geophilic

这三个包都是**纯世界生成**，不加怪、不加物品，只是让跑图更有东西看。

### Terralith —— 地形与群系大修

- **95 个新生物群系**，其中 **11 个是洞穴群系**（正常挖矿也会撞上），例如：
  火山口、紫水晶峡谷、樱花谷、沙漠绿洲、冰川裂谷、约塞米蒂悬崖、白色方山、
  高山针叶林、远古沙海、繁花高原、薰衣草森林、黄石、地幔洞穴、地热洞穴、
  蠹虫洞穴、真菌洞穴……
- **28 种新结构 + 7 个结构集**（结构集：地下地牢、地下建筑、废墟、普通建筑、
  法师建筑、稀有地牢、稀有村庄）：
- 结构举例：法师塔（春 / 夏 / 秋 / 冬四款，外加法师建筑群）、要塞村庄、
  沙漠要塞村庄、沙漠前哨、矿井前哨、冰川小屋、冰屋、冰封地牢、山谷旅舍、
  地下小屋、地下女巫小屋、女巫小屋、沉没高塔、旧炼油厂、巨型蜂巢、尖塔，
  以及森林 / 丛林 / 沙漠 / 方山 / 群山 / 针叶林六类废墟
- 群系名、结构名**已汉化**，按 `F3` 能直接看到中文群系名

### Structory —— 散落世界的遗迹

**15 类结构 + 5 个结构集**，共 238 个结构模板（其中大量是纯装饰件，比如告示牌、
桌椅、篝火堆，所以「238」听着吓人，实际是很多小零件拼出来的）。
结构集为：废墟、中型稀有废墟、幽静废墟、旧庄园、流浪者。

| 结构 | 说明 |
| --- | --- |
| 废弃营地 / 旧庄园 / 墓地 | 适合当出生点附近的第一处据点 |
| 废弃礼拜堂 / 密林废墟 | 主世界森林与丛林中 |
| 沼泽废墟、北方废墟、草地废墟、丛林废墟 | 水域、针叶林与林地地带 |
| 沙漠流浪者 / 草原流浪者 | 有人住过的小屋，常有储物 |
| 地表针叶林遗迹 / 地下针叶林遗迹 | 同一结构分地上地下两种 |
| 瞭望火塔、废弃木船 | 高处视野点 / 水域残骸 |

### Geophilic —— 把原版地形做细

- 覆盖 **29 个原版生物群系**，往里面塞倒木、树桩、灌木丛、花丛、碎石堆、
  地表矿脉、改造过的熔岩湖
- **纯装饰**：不加结构、不加怪物，只让原版地形看起来更自然
- 它改的是**原版群系**，所以群系名还是原版中文，不是它「没汉化」

## 四、独立维度：Deeper Dark「深渊核心」

> 全套内容已汉化，成就线、附魔、物品名都是中文。

### 怎么进去

::: tip 进入方式
1. 拿到**回响碎片**（主手拿着）
2. 走到**远古城市**的传送门框架，站上**强化深板岩**
3. 直接被传送进深渊核心——**不需要打火石**

进深渊核心时系统会给你一枚记录了入口坐标的**入口碎片**，想回来就拿着它原路返回。
:::

- 若你正在被**监守者**追杀（50 格内有监守者），出口会把你拦下——成就「被拒之门外」
- 传送有冷却，别指望连跳

### 7 个生物群系

| 群系 | 特点 |
| --- | --- |
| 深渊核心 | 维度基础群系 |
| 远古黑暗 | 幽匿的故乡，触碰幽匿会被它「记住」 |
| 深渊核心洞穴 | 主体洞穴层 |
| 火山洞窟 | 熔岩与火光 |
| 紫水晶矿坑 | 配套紫水晶矿井结构 |
| 深处绿洲 | 稀有水源绿洲 |
| 黑曜石屏障 | 地下边界层 |

### 5 类结构

紫水晶矿井、远古堡垒、远古村落、实验室、幽匿陷阱。
三种**定位罗盘**可以帮你找它们：紫水晶矿井定位罗盘、远古堡垒定位罗盘、实验室定位罗盘。

找不到也可以用命令一步定位：`/locate structure deeper_dark:amethyst_mineshaft`，
把末尾换成 `ancient_fortress` / `ancient_village` / `laboratory` / `sculk_trap`
就能找其它几种。

### 7 个附魔（附在不同部位）

| 附魔 | 部位 | 效果 |
| --- | --- | --- |
| 明目 | 头盔 | 清除失明 I，减轻黑暗影响 |
| 音波爆轰 | 胸甲 | 充能后发射音波攻击（可自定义伤害） |
| 安然落地 | 护腿 | 提高安全掉落高度 |
| 暗影疾行 | 靴子 | 完全黑暗中提升移速 |
| 共鸣 | 盾牌 | 攻击者发光，并能格挡音波攻击 |
| 尖啸感知 | 望远镜 | 隔墙标示你瞄准的尖啸体或监守者 |
| 深掘 | 工具 | Y=0 以下或在深渊核心中挖掘更快 |

### 核心机制

- **Boss「守卫者」**：带专属血条，击败后有独立成就
- **幽匿转化器**：把物品丢进转化器，用「附魔追加」为已附魔物品再随机加一条相容附魔
- **幽匿触手 / 之爪 / 虹吸器 / 反催化剂 / 音波冲击枪**：投掷放置的方块型道具
- **监守者追踪器**：手持会读出「远古黑暗注意到你了」的警告等级
- **冲击波**：会摧毁地形的音波攻击（可被游戏规则开关）

### 成就是它的任务线

按背包里的**成就页签**（或按 `L`）打开进度面板，从「宝藏与危险」一路做到
「当黑暗褪去之时……」，基本就是这个维度的完整流程攻略。

## 五、独立维度：Ruined「废土纪元」

> 全套内容已汉化。这是一个**放射性荒原玩法大修**，独立于原版生存之外的一整套系统。

### 怎么进去

::: tip 进入方式
主世界会**自然生成「入口废墟」结构**（不是能自己搭的门）。
走进去就会被自动传送进废土，出生点在高空（自带缓降与抗性，不会摔死）。
从废土回来同样走入口结构。
:::

找不到入口时，按它的生成规则排查这三条：

1. **只在这 17 种主世界群系生成**：平原、向日葵平原、森林、繁花森林、白桦林、
   古白桦林、黑森林、针叶林、古松木针叶林、古云杉针叶林、草甸、樱花林、丛林、
   稀疏丛林、竹丛林、热带草原、热带草原高原——沙漠、山地、海洋、雪原都不会出
2. **每 36 区块（约 576×576 格）才有 1 个候选点**，且候选位置在区域内随机，
   不是整齐的网格，跑图时留意地面上的废墟
3. **只在还没生成过的区块出现**：已探索过的老区域永远不会有，要往没走过的地方找

嫌麻烦可以一步到位：**`/locate structure ruined:entrance`** 直接给出最近入口的坐标；
报「找不到」就先往远处飞一段再用。

### 18 个生物群系

**陆地群系（15 个）**：辐照废土、剧毒平原、死木林、灰烬荒原、爆轰之地、
酸液沼泽、硫磺温泉、玻璃旷野、锈蚀荒原、沉沦废土、辐木林、枯骨旱地、
真菌隔离区、冲击高地、黑水泥沼

**河流群系（3 个）**：酸液河、硫磺河、黑水河

### 手持扫描道具（信息显示在动作栏）

废土的扫描道具都拿在**主手**才生效，不拿在手上就什么都不显示：

| 道具 | 动作栏显示 | 说明 |
| --- | --- | --- |
| 盖革计数器 | `盖革：较低 / 升高 / 危险` | 按最近变异体的距离分档：40 格内「升高」，16 格内「危险」 |
| 信号扫描仪 | 当前群系的中文名 | 走到哪个群系就显示哪个 |
| 生物群系勘测仪 | 当前群系的中文名 | 与扫描仪同类 |

副手位也有讲究（放上去就自动生效）：**铅衬钢板** = 护甲与辐射屏蔽，
还能压低身上的辐射值；**野外提灯** = 夜视与微弱萤火光；
**相位核心** = 潜行触发主动相位转移。

## 六、战斗塔 battle_towers

- **主世界和下界各有一套**战斗塔，随世界随机生成
- 每座塔分三层：塔基 `start`、楼层 `floor`、塔顶 `top`
- 楼层刷怪笼 + 战利品箱，塔顶是奖励层

塔是前期练级和刷装备最稳定的地方，看到塔就上去清一层拿一层。

## 常见问题

::: warning 关于这几个包
1. **为什么我看不到新地形？** —— 只在新生成的区块生效，`/rtp` 去远处，或者往没走过的
   方向跑。已探索的区域不会凭空变形。
2. **要装模组或资源包吗？** —— 不用，全是服务端数据包，Java 和基岩进服就自动生效，
   客户端什么都不用动。
3. **名字还是英文怎么办？** —— 本服 8 个数据包**已全部处理**：7 个做了中文汉化，
   Geophilic 改的是原版群系，原版本来就是中文。如果仍看到英文，先 `/reload` 或重启。
4. **这些内容会影响服务器流畅度吗？** —— 世界生成类的包只在生成区块时计算，平时不占
   性能；带常驻逻辑的包（Incendium、两个独立维度）服务端已做过优化，正常玩感觉不到。
5. **该先玩哪个？** —— 新手先照主线：跑图用 `/rtp` 看新地形（见
   [世界生成类数据包](./datapacks-worldgen)），装备成型后再进
   [深渊核心](#四-独立维度-deeper-dark-深渊核心) 和 [废土纪元](#五-独立维度-ruined-废土纪元)。
:::

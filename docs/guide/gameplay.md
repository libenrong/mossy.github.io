# 核心玩法

这一页讲的是**这个服实际有什么**，不是泛泛的 Minecraft 攻略。

## 双端互通：Java 和基岩同一个世界

Java 玩家和基岩玩家（手机、主机、Win10）在**同一张地图**里生存：
一起挖矿、一起建家、聊天互通，装备背包也互通。

- 基岩版玩家 ID 前面会带一个 `-` 前缀，这是区分两端的标志
- 基岩版不需要正版账号（Floodgate 免正版）
- 两端都能用正版/离线方式进服，地址都是 `mossymc.top`

## 科技魔法：Slimefun

输入 `/sf` 打开指南。Slimefun 是一套**不装模组也能玩**的科技与魔法系统：

- 从手搓电路起步，一路攀到自动化设备、量子级机器
- 数百道配方，挖矿 → 电力 → 自动化产线 → 高阶魔法
- 全部在原版客户端里进行，Java / 基岩都能用

喜欢搞自动化的玩家，这几乎是必玩内容。

## 经济：钱从哪来，到哪去

| 玩法 | 怎么参与 |
| --- | --- |
| 系统商店 | `/sashop` 打开 GUI，低买高卖倒物资 |
| 玩家市场 | `/spm` 摆摊上架，定价全看你自己 |
| 现钱交易 | `/bal` 看余额，`/pay` 转账，`/baltop` 看谁最富 |
| 红包 | `/fhb` 发红包，`/qhb` 抢红包，聊天栏手慢无 |

赚到的钱目前主要用于玩家之间交易与市场流通，
具体消费玩法以游戏内为准。

## 战令 · 签到 · 任务 · 称号

- **战令** — `/bp` 打开，完成每日/赛季任务解锁奖励，赛季 30 天一轮
- **签到** — `/signin`，上线第一下点掉，累积奖励、攒点券（点券能换高级通行证）
- **任务** — `/sweettask`（别名 `/task`），每日刷新 5 个任务，每天 4:00 重置
- **称号** — `/plt shop` 商城买称号，`/plt open` 换上，
  聊天栏和头顶立刻和别人不一样

这四个是上线就该点的「日常四连」。

## 技能：挖矿砍树也是升级

`/skills` 打开技能面板，服务器开了 **11 项技能**，全部满级 100：
耕种、伐木、挖矿、钓鱼、考古、箭术、防御、格斗、敏捷、药水、附魔。
挖矿、砍树、钓鱼、打怪都会涨对应技能等级，
升级会解锁被动能力，还会攒**魔法能力**（技能里能看到）。
看自己属性用 `/stats`，看排行榜用 `/skills top`。

## 公会与好友

- **公会** — 和朋友建公会共享地盘与仓库，公会命令用 Tab 补全探索
- **好友** — `/friend` 加好友，上线互相当传送锚点
- **传送朋友** — `/tpa <玩家>`，对方 `/tpyes` 你就过去了；
  `/tpahere` 是把对方叫过来

## 领地：你的东西你做主

 `/dom auto_create <名称>` 脚下快速圈地，
 `/dom create <名称>` 精确选点圈地。圈完之后：

- 别人拆不了你的方块、开不了你的箱子
- `/dom member_add` 拉朋友进来一起建
- `/dom tp` 随时传回自己的领地

完整教程见 [领地插件教程](https://doc.ideafox.top/docs/Midnight/midori-dream/dom-help)。

::: warning 不圈地的后果
没圈地的建筑属于无主之地，被拆被偷只能靠管理员事后回滚，
能预防就别赌人心。
:::

## 被偷了怎么办

服务器装有方块记录（CoreProtect）：谁拆的、谁拿的、什么时候，
后台都有账。发现财物损失**截图 + 找管理员**，确认后可以回滚归还。

## 有人捣乱：投票踢出

`/vote` 选人发起投票，聊天框会弹出「✔ 同意 / ✘ 反对」按钮：

- 投票持续 **60 秒**；在线人数超过 10 时需要 **40%** 同意，否则要 **4 票**
- 通过后目标被**临时封禁 30 分钟**
- 同一个人 **300 秒**内只能再发起一次投票

## 舒服的小功能

- **一个菜单点到底** — 手持「菜单」钟右键、**潜行 + F**、或 `/menu`，
  传送/工具/签到/市场/任务全在里面
- `/sit` `/lay` `/crawl` — 坐、躺、趴，社交神器
- `/anvil` `/workbench` `/grindstone` `/smithing` — 随身工作台系列，不用放方块
- `/wtc` 个人垃圾桶、`/worldlisttrashcan globaltrash` 公共垃圾桶，扔错了还能捞
- `/hat` — 手上物品直接戴头上
- `/skin set <皮肤名>`、`/skins` — 换皮肤，Java 基岩都吃
- `/rtp` — 开荒党福音，随叫随走（30 秒冷却）

## 生存难度

服务器是 **hard 困难难度**的原版生存：

- 怪更硬、更疼，夜里出门带火把和床
- **死亡会掉落背包物品** — 重要的东西先 `/dom` 圈起来放箱子
- `/back` 死后可以回到死亡点捡漏（动作要快）

难度是刻意留着的：活着回来的建筑，才配叫作品。

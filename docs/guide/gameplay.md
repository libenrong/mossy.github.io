# 核心玩法

MossyMC 提供六大核心玩法维度，每一种都是一种态度。

## 探索

穿越繁茂洞穴、深邃黑暗，丈量从基岩到天空的每一寸可能。

### 探索要点

- **繁茂洞穴** — 地下深处发光的洞穴生态，蕴含孢子花与发光浆果
- **深邃黑暗** — 监守者潜伏的恐怖地带，潜行是生存的关键
- **末地城** — 紫珀砖与潜影贝守护的宝藏
- **海底神殿** — 与守卫者周旋，获取海晶碎片

::: warning 注意
进入深邃黑暗区域时，请保持潜行状态，避免触发幽匿感测体引来监守者。
:::

## 战斗

挥剑迎击末影龙，在下界要塞中与凋灵展开生死对决。

### 战斗技巧

- **末影龙** — 准备充足的地狱岩、床和弓箭，破坏末地水晶后正面交锋
- **凋灵** — 在下界召唤可避免破坏主世界地形，附魔钻石装备是基础
- **远古守卫者** — 携带夜视药水和水下呼吸头盔
- **袭击** — 村庄英雄效果可触发，准备盾牌和金苹果

## 采集

挥动钻石镐，挖掘远古残骸，收集构建文明的每一块基石。

### 采集路线

| 等级 | 目标 | 工具 |
| --- | --- | --- |
| 前期 | 木材、煤炭、铁矿 | 木/石镐 |
| 中期 | 钻石、金、红石 | 铁镐 |
| 后期 | 远古残骸、绿宝石 | 钻石/下界合金镐 |

::: tip 远古残骸
在下界 Y=15 高度，用床爆炸法可高效获取远古残骸，合成下界合金锭。
:::

## 建造

从红石机械到摩天城堡，将想象力浇筑进每一个方块。

### 建造入门

- **基础结构** — 先搭框架再填墙体，保持比例协调
- **配色方案** — 选择 2-3 种主色调，避免过度杂乱
- **光影层次** — 利用台阶、楼梯、墙创造深度感
- **地形融合** — 让建筑与自然环境融为一体

## 合成

在工作台中调配万物，从木剑到附魔装备，创造你的工具谱系。

### 合成进阶

- **附魔台** — 用书架（15个）环绕附魔台可达最高附魔等级
- **铁砧修复** — 合并附魔书与装备，消耗经验值
- **酿造台** — 烈焰粉为燃料，地狱疣为基底，调配各类药水

## 红石

用红石电路编织自动化机械，让方块世界拥有心跳与脉搏。

### 红石基础元件

- **红石粉** — 传递信号，最远 15 格
- **中继器** — 延长信号并可延迟 1-4 刻
- **比较器** — 检测物品数量、模拟减法运算
- **观察者** — 检测方块状态变化，触发脉冲

::: tip 入门项目
从自动农场（甘蔗/小麦）开始，逐步挑战物品分类系统和飞行器。
:::

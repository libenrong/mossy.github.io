# 04 · 配置系统

## 核心原则：只改 `/config.yml`

Leaf（继承自 Paper 的统一配置思路）在**每次启动**时：

1. 读取根目录 `/config.yml`（约 128KB，含全部分层键）；
2. 按前缀把值**写回**下游文件：
   - `bukkit.yml` ← `bukkit.*`
   - `spigot.yml` ← `spigot.*`
   - `config/paper-global.yml`、`config/paper-world-defaults.yml` ← `paper.*`
   - `config/leaf-global.yml` 等 ← `leaf.*`
   - `config/gale-global.yml` 等 ← `gale.*`
3. 运行期内存里用的是合并后的配置对象。

**因此：**

- ✅ 改性能/游戏规则/网络键 → 改 `/config.yml`，重启生效。
- ❌ 直接改 `bukkit.yml` / `spigot.yml` / `config/paper-*.yml` → 下次启动被覆盖，白改。
- ⚠️ 例外：`server.properties` **不**由 config.yml 生成，是独立文件，直接改（RCON、max-players、motd 等在这里）。
- ⚠️ 例外：各插件自己的 `plugins/Xxx/config.yml` 完全独立，Leaf 不碰。

## mtime 骗人问题

生成文件（bukkit.yml 等）的 mtime 是 Leaf **写回时刻**，不是你上次改动时刻。曾用 mtime 判断「哪个值在跑」时踩过坑：config.yml 18:00 改过，生成文件 07:00 就有——因为中间没重启，生成文件是上次启动写的，跑的是旧值。

**判断「当前生效值」的唯一可靠方法**：看 `/config.yml` 里该键的值 + 确认上次启动时间（日志 `Starting minecraft server version` 行）。

## 配置文件清单

| 文件 | 大小 | 性质 |
|---|---|---|
| `/config.yml` | ~128KB | ★ 唯一入口 |
| `/server.properties` | ~2KB | 独立 |
| `/bukkit.yml` | ~1KB | 生成 |
| `/spigot.yml` | ~5KB | 生成 |
| `/config/paper-global.yml` | ~4KB | 生成 |
| `/config/paper-world-defaults.yml` | ~9KB | 生成 |
| `/config/leaf-global.yml` | ~15KB | 生成 |
| `/config/gale-global.yml` | ~1.4KB | 生成 |
| `/config/gale-world-defaults.yml` | ~1.4KB | 生成 |

## config.yml 里最常动的区段（键名速查）

Leaf 统一配置是扁平/嵌套混合的大 YAML。实际改过的键（详见 [09-性能优化记录](09-性能优化记录.md)）：

```yaml
# 网络
settings.io-threads: 6
settings.netty-threads: 4
settings.optimize-non-flush-packet-sending: false   # 原拼写错误 flase

# 实体 AI / 刷怪
settings.async-pathfinding.max-threads: 6
settings.async-entity-tracker.max-threads: 6
settings.entity-activation-range.animals: 16
settings.entity-activation-range.monsters: 16
settings.entity-activation-range.raiders: 64

# 漏斗
settings.hopper-check: 8
settings.hopper.disable-move-event: false   # QuickShop 需要 false

# 存档/区块
settings.region-file-cache-size: 2048
settings.save-user-cache-on-stop-only: true

# 杂项
settings.world-settings.default.los-lookup-interval: 10
settings.world-settings.default.stats-player-sync-interval: 100
settings.log-villager-deaths: false
settings.skip-tripwire-hook-placement-validation: true
settings.fix-mc-152094: true
```

（键名以 `/config.yml` 实际内容为准；不同 Leaf 小版本键名可能有漂移，改前先 grep 确认存在。）

## server.properties 关键项

```properties
max-players=50
enable-status=true
enable-query=false
enable-rcon=false              # 无远程控制台的根源
online-mode=true
spawn-protection=16
view-distance=10                # 若有；以实际文件为准
motd=…
```

改 `max-players`、`motd`、`view-distance` 直接编辑此文件，重启生效。

## 修改配置的标准流程

1. `getbin` 拉当前 `/config.yml` 到本地；
2. 本地编辑（保留注释与结构；用 YAML 校验器过一遍）；
3. `up.mjs` 传回，**确认 md5**；
4. 面板重启；
5. 重启后：`grep` 日志确认无 config 相关 warning；必要时 `getbin` 拉回生成文件抽查该键已写入。

## 快速上手三件事

1. **没有远程控制台**。`enable-rcon=false`，EasyBot 只外连 QQ 桥。一切「执行命令」都得进主机面板或游戏内以 OP 操作。
2. **改配置只改 `/config.yml`**。Leaf 启动时把它写回 bukkit/spigot/paper/leaf/gale 各层；手改生成文件会在下次启动被覆盖。
3. **重启前看 [11-运维操作规程](11-运维操作规程.md) 的 checklist**。上一次事故（废土世界丢失）的根因就是重打包时漏了 `pack.mcmeta`。

## 文档维护

- 每次变更服务器后更新对应章节，并在 [03-更新日志](03-更新日志.md) 追加条目。
- 凭据不写进本目录；SFTP/MySQL 密码见本机 `srv/conn.mjs` 与 `/plugins/CoreProtect/config.yml`。

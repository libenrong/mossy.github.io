## 分世界背包（Multiverse-Inventories 5.3.5）

### 存储位置

```
plugins/Multiverse-Inventories/
  config.yml          总开关与保存策略
  groups.yml          世界分组（哪些世界共享背包）
  worlds/
    world/<玩家名>.json
    world_nether/<玩家名>.json        （若分组隔离）
    world_ruined_ruined/<玩家名>.json
    …
  players/            每玩家元数据（小 JSON）
```

**没有** `playerdata/<uuid>.dat` 权威数据。`/world/playerdata/` 对活跃玩家为空或缺失。

### JSON 结构（实测）

```json
{
  "SURVIVAL": {
    "inventoryContents": { "0": {…ItemStack…}, "1": {…}, … },
    "armorContents": { "0": {…}, "1": {…}, "2": {…}, "3": {…} },
    "offHandItem": {…},
    "enderChestContents": { "0": {…}, … },
    …可能还有其他游戏模式键
  }
}
```

ItemStack 格式（Bukkit 序列化）：

```json
{
  "==": "org.bukkit.inventory.ItemStack",
  "DataVersion": 4903,
  "id": "minecraft:netherite_sword",
  "count": 1,
  "components": {
    "minecraft:enchantments": "{\"minecraft:sharpness\":10,…}",
    "minecraft:custom_name": "…",
    "minecraft:container": "[…]"     // 潜影盒内容，SNBT 风格字符串
  },
  "schema_version": 1
}
```

注意：
- `components` 的值多为**字符串化的 JSON/SNBT**（双重编码），不是内嵌对象。
- 潜影盒内容在 `minecraft:container` 里，格式是 `{item:{id:…},slot:N},…`（键无引号），不是标准 JSON，解析要小心。
- 附魔在 `minecraft:enchantments`（装备）或 `minecraft:stored_enchantments`（附魔书）。

### 改背包的铁律

1. **必须趁玩家离线**。在线时改文件，玩家退服/切世界时 MV 会把内存中的会话写回，覆盖你的修改。
2. 改前重新 `getbin` 拉最新文件（文件 mtime 会随在线保存而变）。
3. 改后 `up.mjs` 上传并核 md5。
4. 给物品的组件格式参考同文件内已有物品（DataVersion 4903）。

### 分世界背包 vs 玩家体验

玩家在 A 世界有一套装备、进 B 世界换成 B 世界那套。废土世界坏了时，玩家「回到」主世界会拿到主世界背包——废土里穿着/带着的东西看起来「丢了」，实际还躺在 `worlds/world_ruined_ruined/<名>.json` 里，世界恢复后进去就能取回。

# 06 · 数据包手册

数据包按世界隔离，路径 `<世界>/datapacks/`。改包 = 替换 zip → 重启（或 `/datapack enable`，但维度创建类问题必须重启）。

### 刷怪函数修复（已打进包里）

`mobs/check_owner.mcfunction`、`mobs/limit.mcfunction` 中，`/kill` 前加：

```
data modify entity @s DeathLootTable set value "minecraft:empty"
```

- 背景：废土变异怪按坐标分区刷，玩家超距（>112 格）或同屏 ≥7 只触发清理；`/kill` 按 generic 死亡刷掉落物，单日 4697 条「was killed」日志 + 物品刷屏
- 影响面：只影响系统清理的怪；玩家击杀走原掉落表，不变

```
此后   等重启重建
```

**给包时永远先验三件事**：
1. `pack.mcmeta` 在 zip **根目录**（不是嵌套文件夹里）
2. `unzip -l` 文件数与预期一致
3. 关键 JSON（enchantment 等）能 `json.load` 通过

## 数据包操作速查

```bash
# 本地检查包
unzip -l wasteland_zh.zip | head
python3 -c "import zipfile,json; z=zipfile.ZipFile('x.zip'); print('pack.mcmeta' in z.namelist())"

# 上传
cd srv && node up.mjs /本地/x.zip /world/datapacks/x.zip

# 游戏内（重启前预览，不推荐用于维度包）
/datapack list
/datapack enable file/x.zip
```

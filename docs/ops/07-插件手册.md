## 1. 基座/库

### LuckPerms 5.5.57
- **作用**：权限组、prefix、跨服组（本服单服）。
- **配置**：`plugins/LuckPerms/config.yml`（35KB 全量默认+注释）。存储后端未细查，大概率 H2 文件库。
- **运维命令**：`/lp group <组> permission set <节点> true`、`/lp user <玩家> parent set <组>`。
- **注意**：与 AuthMe 联动登录后应用组；改权限后无需重启。

### VaultUnlocked 2.20.2
- **作用**：经济/权限 API 中介。XConomy 挂 provider，商店类插件从这里取余额。
- **注意**：VaultUnlocked 是维护分支（原 Vault 停更）；不要与旧 Vault jar 同时放。

### PlaceholderAPI 2.12.3
- **作用**：`%xxx%` 占位符给 TrChat/KaMenu/mini motd 等用。
- **常用占位**：`%vault_eco_balance%`、LuckPerms 的 `%luckperms_prefix%`、ServerCore/自定义扩展视已装 expansion 而定。

### ProtocolLib 5.5.0 / packetevents 2.13.0
- **作用**：包级 API。KaMenu、TrChat、SkinsRestorer 等依赖其中之一或两者。
- **注意**：Minecraft 26.x 的协议号变动大，这两者的版本必须匹配 Leaf 分支；升级 MC 时先确认兼容。

### nightcore 2.15.2
- **作用**：NightExpress/NightShop 系插件的公共库（或独立工具库）。无直接命令。

## 2. 多世界/传送

### Multiverse-Core 5.8.1-pre.1
- **作用**：世界注册/卸载/传送、生成规则、入口费（本服 `entry-fee.enabled: false`）。
- **配置**：`plugins/Multiverse-Core/worlds.yml`（8.4KB，五个维度键）、`config.yml`（16KB）。
- **已知事件**：2026-10-10 废土维度因数据包 `Missing metadata` 创建失败，日志 `Failed to create bukkit world: ruined_ruined`。详见 [03-更新日志](03-更新日志.md)。

### Multiverse-Inventories 5.3.5
- **作用**：分世界背包/盔甲/末影箱。**权威玩家物品存储在 JSON，无 .dat**。
- **配置**：
  - `config.yml`（7.5KB）：全局开关、保存策略
  - `groups.yml`（340B）：世界分组（共享/隔离）
  - `worlds/<世界>/<玩家名>.json`：实际背包
- **铁律**：改 JSON 必须趁玩家离线；在线修改会被退服/切世界时的会话保存覆盖。
- **格式细节**：见 [05-世界与多世界](05-世界与多世界.md)。

### SimpleRTP 5.4
- **作用**：`/rtp` 随机传送。有冷却、世界白名单、边界限制（主世界大地图下注意别把人丢进废土故障区）。

### MinecraftWarps 1.0.0
- **作用**：命名传送点 `/warp`。数据在其目录内。

## 3. 经济/商店

### XConomy-Paper 2.26.3
- **作用**：服务器经济主库（余额、转账、定时发放）。Vault provider。
- **配置**：`plugins/XConomy/config.yml`（5KB）。
- **运维**：`/pay`、`/baltop`；OP 补款 `/money give <玩家> <数额>`（以实际子命令为准）。

### QuickShop-Hikari 6.3.0.0
- **作用**：箱子商店（收购/出售）。依赖 Hikari 连接池。
- **配置**：`plugins/QuickShop-Hikari/config.yml`（32KB 全量）。
- **与性能配置联动**：`paper.hopper.disable-move-event` 必须为 **false**（2026-10-10 已改），否则商店漏斗检测失效；`hopper-check: 8` 兼顾扫描频率。
- **注意**：经济刷物品漏洞多发插件，关注其 changelog 安全补丁。

### SweetAdaptiveShop 1.2.4 / SweetPlayerMarket 1.0.19 / SweetTask 1.0.6
- **作用**：Sweet 系——自适应定价商店、玩家间市场、任务。
- **注意**：三者共享经济 API；改价格曲线前备份其配置目录。

## 4. 玩法

### Slimefun 2026.1
- **作用**：科技/魔法大杂烩（研究、合成台、便携机器）。
- **配置**：`plugins/Slimefun/config.yml`（2.5KB）。
- **profile-storage.yml**（2026-10-10 改）：`maxLifetime: 300000`、`connectionTimeout: 10000`——缓解远程 MySQL 抖动引发的 Hikari 连接风暴（01:20 事故）。
- **数据**：玩家研究进度在 `plugins/Slimefun/` 下（文件或数据库，视 config）。

## 6. 登录/合规

### AuthMe-6.0.0-Paper
- **作用**：登录验证（密码、IP 绑定、注册）。
- **配置**：`plugins/AuthMe/config.yml`（31KB 全量）。

## 8. 运维

### CoreProtect 24.0.2-dev
- **作用**：方块/容器/死亡流水查询与回滚。
- **数据**：MySQL `160.202.254.65:33306`（库 `coreprotect`，用户 `minecraft`，**IP 白名单**——外部 TCP 握手会被 reset）。
- **游戏内**：`/co l`（lookup）、`/co i`（inspect 手持）、`/co rollback`。
- **配置**：`plugins/CoreProtect/config.yml`（4.4KB）。

### Chunky-Bukkit-1.5.3
- **作用**：预生成区块（`/chunky radius` / `start`）。开新世界或防卡顿预热用。

### InvAutoBackup 1.0.0（2026-10-11 新装）
- **作用**：定时/退服/关服自动备份玩家背包状态（YAML 明文）。
- **配置**：`plugins/InvAutoBackup/config.yml`（`interval-minutes: 10`、`keep-per-player: 288`、`backup-on-quit: true`）。
- **命令**：`/invbak now|list|restore <文件名>`（权限 `invbak.use` / `invbak.restore`，默认 OP）。
- **路径**：`plugins/InvAutoBackup/backups/<uuid>/<yyyyMMdd-HHmmss>-<reason>.yml`。
- **加载状态**：已上传，**待重启加载**。
- **详见** [08-备份与恢复](08-备份与恢复.md)。

### EasyBot-2.4.0
- **作用**：QQ 群机器人桥（群号 391425109），验证绑定、消息同步。
- **配置**：`plugins/EasyBot/config.yml`（3.8KB）。`ignore_error: true`——桥挂了不拦登录。
- **网络**：**外连** `ws://160.202.254.65:26990/bridge`（token 在 config）。不是本地服务，**不能当 RCON 用**。

### SkinsRestorer-15.12.4
- **作用**：皮肤/披风。对 26.x 的会话服务器适配需关注更新。

### minimotd-paper-2.2.4
- **作用**：MOTD 动态化（PlaceholderAPI、玩家数显示）。

### betterview-paper-2.2.0-all
- **作用**：视距/渲染相关（客户端 mod 配套服务端？以 config 为准）。

### UltimateTweak-1.2.2
- **作用**：杂项性能/行为 tweak 集。**逐项看其 config 确认没开危险开关**。

### DeeperDarkTick.jar
- **作用**：深层黑暗维度 tick 修复/优化（配合 `world_deeper_dark_deeper_dark`）。

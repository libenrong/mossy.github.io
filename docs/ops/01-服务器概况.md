# 01 · 服务器概况

## 基本信息

| 项 | 值 |
|---|---|
| 服务端 | **Leaf** `leaf-26.2-123.jar`（85 MB，位于根目录） |
| 游戏版本 | Minecraft **26.2**（DataVersion **4903**） |
| Java | **GraalVM 25.2.4+7.1**（`/home/container/graalvm-25.2.4+7.1/bin/java`） |
| 堆内存 | `-Xms16G -Xmx16G`（AlwaysPreTouch，实际常驻 16G） |
| 最大玩家 | 50（server.properties） |
| 在线模式 | 是（AuthMe 叠加二次登录验证） |
| 主机 | simpfun 分享型（容器路径 `/home/container`） |
| 时区/语言 | 容器默认；日志时间戳为本地时区 |

Leaf 是 Paper 的社区分支（中国社区维护），在 Paper 之上加了 IO 性能补丁、合并基座（Forge/Neo/Fabric 混跑能力的上游方向）和一批实验开关。本服只用它的 Paper 兼容层 + 性能开关，未启用 mod 加载相关功能。

## 连接方式

### SFTP（文件）

| 项 | 值 |
|---|---|
| 主机 | `sfe4-connect.simpfun.cn` |
| 端口 | `2029` |
| 用户 | `sfe3225333.4019696b` |
| 密码 | 见本机 `srv/conn.mjs`（不写入文档） |
| 根路径 | 登录后即为服务器根（等价于 `/home/container`） |

本机工具链（`srv/` 目录，Node + ssh2）：

```bash
node srv/ls.mjs <远端目录>           # 列目录
node srv/getbin.mjs <远端> <本地>    # 下载
node srv/up.mjs <本地> <远端>        # 上传 + 回读 md5 校验
node srv/getall.mjs …               # 批量下载（串行，带重试）
```

注意：并行开多个 SFTP 连接会被主机掐断（ECONNRESET），所有工具走单连接串行。

### MySQL（CoreProtect 数据）

| 项 | 值 |
|---|---|
| 地址 | `160.202.254.65:33306` |
| 库 | `coreprotect` |
| 用户 | `minecraft` |
| 密码 | 见 `/plugins/CoreProtect/config.yml` |
| 白名单 | **有**。从外部 TCP 能握手但 MySQL 协议层会被 reset；只有游戏服自身出站能连 |

因此：查 CoreProtect 历史只能让 OP 在游戏内 `/co l`、`/co i`，或从服务器上另想办法，不能本地直连。

### 控制台 / RCON

- `enable-rcon=false`（server.properties），`rcon.password` 为空。
- EasyBot 2.4.0 是 QQ 群机器人桥，**外连** `ws://160.202.254.65:26990/bridge`（token 在其 config.yml），不是本地 HTTP 服务，无法借用它执行命令。
- **结论：远程执行服务器命令的通道为零。** 重启、reload、give 等都必须：
  1. 主机面板操作（重启类），或
  2. 游戏内 OP 账号执行，或
  3. 离线改文件（背包、配置类）。

## 权限与账号

- 游戏内权限：LuckPerms 5.5.57。
- 登录：AuthMe 6.0.0（用户名/密码 + IP 绑定策略），EasyBot 提供 QQ 绑定验证（`ignore_error: true`，桥连不上时放行登录）。
- 玩家名别名：AuthMe 记录多账号绑定，如 `YonmkoQWQ` ↔ `ymk_qaq_777`（同一人）。

## 玩家规模与活跃度（2026-10 观察）

- 峰值在线个位数，常见 1–5 人。
- 活跃玩家约 20–30 个有历史数据；MV 背包文件约 55 个。
- 白天时段（10:00–23:00 +0800）有零星登录，晚间略多。

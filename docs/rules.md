# 服务器规则

为维护良好的游戏环境，请所有玩家遵守以下规则。

::: warning 注意
以下为 Minecraft 服务器通用规则参考，最终规则以服务器内公告和 `/rules` 命令输出为准。违反规则可能导致警告、封禁等处理。
:::

## 基本准则

1. **尊重他人** — 禁止任何形式的辱骂、歧视、骚扰行为
2. **公平游戏** — 禁止使用外挂、作弊客户端、宏按键等第三方作弊工具
3. **诚信交易** — 禁止诈骗、虚假交易、利用漏洞牟利

## 建筑与领地

1. **尊重领地** — 不得未经允许进入或破坏他人领地
2. **禁止恶意破坏** — 不得在他人建筑附近恶意建造或破坏地形
3. **合理选址** — 建造前请先认领领地，避免与他人建筑冲突
4. **公共区域** — 出生点及公共区域禁止私建，听从管理员指引

## 聊天与社交

1. **文明发言** — 禁止刷屏、广告、色情、暴力等不当言论
2. **语言规范** — 请使用中文或英文交流，方便管理员管理
3. **禁止冒充** — 不得冒充管理员或其他玩家
4. **私聊礼仪** — 骚扰性私聊将被处理

## 游戏行为

1. **禁止利用漏洞** — 发现漏洞请及时上报，利用漏洞牟利将受处罚
2. **禁止卡服** — 不得故意制造大量实体或红石机械导致服务器卡顿
3. **禁止多账号** — 每位玩家限一个账号，小号需向管理员报备
4. **PVP 规则** — 在允许 PVP 的区域进行公平战斗，禁止恶意追杀

## 处罚机制

| 违规程度 | 处理方式 |
| --- | --- |
| 轻微违规 | 警告或禁言 |
| 一般违规 | 临时封禁（1-7 天） |
| 严重违规 | 永久封禁 |

::: info 申诉
如对处罚有异议，可通过管理员申诉。请保留相关截图证据。
:::

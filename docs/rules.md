# 服务器规则

为维护良好的游戏环境，请所有玩家遵守以下规则。

::: warning 注意
最终规则以服务器内公告为准。违反规则可能导致警告、禁言、封禁等处理。
有争议先截图，通过 QQ 群 **391425109** 找管理员沟通。
:::

## 基本准则

1. **尊重他人** — 禁止任何形式的辱骂、歧视、骚扰行为
2. **公平游戏** — 禁止使用外挂、作弊客户端、宏按键等第三方作弊工具
3. **诚信交易** — 禁止诈骗、虚假交易、利用漏洞牟利
4. **保管好自己的账号** — 服务器是密码注册制，密码只有你自己知道；
   共用账号、把密码给他人导致的损失，管理员无法负责

## 建筑与领地

1. **先圈地再盖房** — 用 `/dom` 认领领地，圈内的东西才真正属于你
2. **尊重他人领地** — 不得未经允许进入或破坏他人领地
3. **禁止恶意破坏** — 不得在他人建筑附近恶意建造或破坏地形
4. **公共区域** — 出生点及公共区域禁止私建，听从管理员指引

## 聊天与社交

1. **文明发言** — 禁止刷屏、广告、色情、暴力等不当言论
2. **语言规范** — 请使用中文或英文交流，方便管理员管理
3. **禁止冒充** — 不得冒充管理员或其他玩家
4. **私聊礼仪** — 骚扰性私聊将被处理

## 游戏行为

1. **禁止利用漏洞** — 发现漏洞请及时上报，利用漏洞牟利将受处罚
2. **禁止卡服** — 不得故意制造大量实体或红石机械导致服务器卡顿
3. **禁止多账号** — 每位玩家限一个账号，小号需向管理员报备
4. **PVP 规则** — 在允许 PVP 的区域进行公平战斗，禁止恶意追杀
5. **别碰别人的东西** — 拆方块、开箱子、顺手牵羊都算偷，
   方块记录（CoreProtect）留痕，查出来直接回滚 + 处罚

## 处罚机制

| 违规程度 | 处理方式 |
| --- | --- |
| 轻微违规 | 警告或禁言 |
| 一般违规 | 临时封禁（1-7 天） |
| 严重违规 | 永久封禁 |

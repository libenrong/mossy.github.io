# 常见问题

按玩家问得最多的顺序排列。

## 支持哪些版本？

| 端 | 版本 |
| --- | --- |
| Java 版 | **1.21.7 — 26.2**（推荐 1.21.7 起） |
| 基岩版 | 26.30 / 26.31 |

官方更新日志写明：**最低支持版本为 JE 1.21.7**，同时支持 JE 26.2 与 BE 26.30/31；
菜单用的是 1.21.6+ 的 Dialog 界面，所以推荐 1.21.7 起进服。
JE 26.2 客户端因为 Via 的已知 bug，暂时不建议使用。
服务器列表里显示的「游戏版本 26.2」就是服务端版本。

## 菜单怎么打开？

三种方式，随便挑一个：

1. 手持**「菜单」钟**右键（进服会自动发给你一个）
2. **潜行 + F**（切换副手键，必须先潜行）
3. 输入 `/menu`

传送、工具、签到、市场、任务、红包、领地全在这一个菜单里。

## 要正版账号吗？怎么登录？

**不是强制正版。** 服务器为注册制：

1. 第一次进服：`/register <密码> <密码>`
2. 以后每次进服：`/login <密码>`
3. 改密码：`/changepassword <旧密码> <新密码>`

基岩版玩家走 Floodgate，**不需要正版**，ID 会自动带 `-` 前缀。
密码就是你的账号，丢了很难找回，请自己保管好。

## 连不上服务器怎么办？

按顺序试：

1. 地址只填 `mossymc.top`（不要 `http://`，不要带端口）
2. 客户端版本太旧会被挡，推荐升到 1.21.7+
3. 换直连地址 `play.simpfun.cn:30843`
4. 卡在登录界面就退出重进，再 `/login`
5. 还不行 → QQ 群 **391425109** 发报错截图

## 我是基岩版，怎么变成 Java 玩家了？

Floodgate 的已知问题：基岩玩家偶尔会被识别成 Java 玩家，
表现为需要重新注册、背包好像丢了、基岩专属菜单用不了。

**解决：立刻退出服务器再重进。** 尽量不要重复注册。
看自己 ID 前面有没有 `-` 就知道有没有中招。

## 可以加模组吗？

- **服务端**是插件服，装不了服务端 Mod
- **客户端**可以加辅助类 Mod：JEI、Jade、Carpet 等都没问题
- 什么都不加也能玩，Slimefun（`/sf`）本身就在服务器里

## 死亡会掉落东西吗？

会。困难难度原版生存，死亡掉落背包物品。

- 贵重物品放进领地里的箱子（`/dom` 圈地）
- 死后 `/back` 能回到死亡点，动作要快

## 怎么保护自己的建筑？

`/dom auto_create <名称>` 脚下快速圈地，
之后别人就拆不了你的方块、开不了你的箱子。
朋友用 `/dom member_add` 拉进来一起建。
教程：[领地插件教程](https://doc.ideafox.top/docs/Midnight/midori-dream/dom-help)。

## 怎么赚钱？

- `/sashop` 系统商店倒买倒卖
- `/spm` 玩家市场摆摊，定价随你
- `/bal` 看余额，`/baltop` 看排行榜
- 手气：`/qhb` 抢聊天栏红包

## 怎么去朋友那里？

`/tpa <朋友ID>`，对方 `/tpyes` 同意后你就会过去。
反过来让朋友 `/tpa` 你，或者你用 `/tpahere` 把对方叫过来。
不想被骚扰就 `/tptoggle` 关掉传送请求。

## 忘记密码了怎么办？

密码只在你自己手里，管理员**无法直接告诉你密码**。
加 QQ 群 **391425109** 说明情况，按管理员指引处理；
提供不了足够证明的话，可能只能重新注册（旧物品难找回）。

## 服务器会卡吗？会重置吗？

服务端 16G 内存 + 针对性优化，日常不卡；
偶发卡顿管理员会处理。世界长期保留，不会随便重置；
若有大改需要重置，会提前在 QQ 群公告。

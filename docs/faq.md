# 常见问题

## 如何加入服务器？

在 Minecraft Java 版多人游戏中添加服务器，地址填入 `mossymc.top` 即可。详细步骤参见 [新手入门](/guide/getting-started)。

## 支持哪些版本？

服务器支持 Java 版，基岩版同步开放。具体版本号以服务器内公告为准，可在游戏内输入 `/motd` 查看。

## 服务器是正版验证吗？

请以服务器实际配置为准。若提示「未验证用户名」，说明服务器开启正版验证，需使用正版账号登录。

## 如何保护我的建筑？

使用领地命令 `/claim`（手持金锭圈选区域）认领你的领地。认领后其他玩家无法破坏或进入。详见 [常用命令](/guide/commands#领地命令)。

## 死亡后会掉落物品吗？

默认情况下死亡会掉落物品。建议：
- 随身携带床并设置 `/sethome`
- 重要物资存放在领地内的箱子中
- 使用 `/back` 返回死亡地点拾取物品（如有该权限）

## 如何传送到朋友身边？

使用 `/tpa <朋友ID>` 发送传送请求，对方输入 `/tpaccept` 接受后即可传送。

## 如何赚钱？

常见方式包括：
- 出售物资给系统商店
- 与其他玩家交易
- 参与服务器活动

输入 `/balance` 查看余额，`/baltop` 查看排行榜。

## 遇到玩家违规怎么办？

- 截图保留证据
- 在游戏内使用举报命令（如有）
- 联系在线管理员处理

## 如何成为管理员？

管理员招募以服务器公告为准。通常需要：
- 活跃在线时长
- 熟悉服务器规则与命令
- 良好的社区声誉

## 服务器会重置吗？

服务器世界一般长期保留。如遇版本大更新或特殊情况需要重置，管理员会提前公告。建议将重要建筑和物资存放在领地内。

## 还有一个问题没解决？

在游戏内向管理员求助，或通过社区渠道反馈。规则详见 [服务器规则](/rules)。
